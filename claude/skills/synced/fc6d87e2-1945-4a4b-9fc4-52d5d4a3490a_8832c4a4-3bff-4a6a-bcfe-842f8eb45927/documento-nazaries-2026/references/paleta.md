# Paleta de color de Nazaríes

Archivo fuente: `assets/PALETA_NAZARIES_RGB.ase`. Todo el documento usa exclusivamente
estos colores, con una excepción: el gráfico de portada, explicada al final.

## Paleta principal

| Color | Hex | RGB |
|---|---|---|
| Azul Nazaríes | #00333B | 0, 51, 59 |
| Turquesa | #C1E4D6 | 193, 228, 214 |
| Gris | #D2D2D2 | 210, 210, 210 |
| Blanco | #FFFFFF | 255, 255, 255 |

## Dónde se usa cada color en el documento

| Elemento | Color |
|---|---|
| Texto base y cabeceras de tabla | #00333B |
| Textos sobre la portada | #C1E4D6 |
| Entradillas de capítulo, texto secundario de tablas, guion de viñeta, encabezados H3 | #66888D |
| Número de gran formato en la apertura de capítulo | #E6E6E6 |
| Fila de total en tablas | #C1E4D6 |
| Fondo de las cajas de nota | #E6F4EF |
| Banda alterna de tablas | #F5F5F5 |
| Línea inferior de la cabecera de continuación | #CCD7D9 |

## Excepción: la portada

La portada conserva los colores originales de bRIDA. El fondo es una rampa de seis tonos
del azul Nazaríes al turquesa (#00333B, #0A3D45, #215457, #457370, #739C96, #C1E4D6):
sustituir los cuatro intermedios por su equivalente oficial más cercano fusiona pares de
tonos y la portada pierde dos de sus cinco capas. Con la rampa se mantienen también el
tono del título (#EAF3EF) y el filete sobre la tabla de datos (#4F7D7A).

La excepción se limita a esa página. Cualquier elemento que el generador escribe en el
cuerpo del documento usa la paleta oficial.

Para elementos nuevos, usar la paleta principal y sus matices. Nada fuera de esta tabla.
